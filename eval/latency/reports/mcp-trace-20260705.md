## Gate decision

Plan reference: stdio initialize median ~116 ms, which the plan already labels as below the bar for building C4. Plan rule: "If the evidence stays near today's local numbers, keep the current Python MCP entry point." This harness encodes 'near' as p50 within 1.5x of that reference (174 ms) for the direct venv entry point.

- direct-entry spawn+initialize p50 134.2 ms is within the plan's 'near today's local numbers' band (<= 174 ms vs the recorded 116 ms median)
- uv-wrapper launch adds 33.7 ms p50 over the direct entry point: client orchestration, fixable by pointing the client at .venv/bin/mneme-mcp, not by a Rust front-end
- warm steady-state read-only call p95 is 1.04 ms: spawn cost is a once-per-session cost, not a per-call tax

**GATE VERDICT: GATE STAYS CLOSED - do not build the C4 Rust front-end** (measured direct-entry spawn+initialize p50 134.2 ms / p95 166.0 ms vs the plan's ~116 ms below-the-bar reference; the 50 ms Rust handshake target remains an unopened optimization).
