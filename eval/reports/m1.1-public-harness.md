# M1.1 public harness

Status: source-complete development scaffold.

The registry-driven `smoke` suite provides a redistributable CLI-only system
test and a canonical, mutation-detecting reproduction bundle. Its dataset is
revision- and SHA-256-pinned, CC0-licensed, and marked as a development
self-test. Bundle verification binds benchmark, configuration, build contract,
judge declaration, metrics, and per-question traces.

This report publishes no benchmark result. The smoke artifact is not
publishable, not PBPP-headline eligible, and not an independent external
reproduction. Those statuses remain false until their separate evidence gates
are met.
