# Phase 08 / Plan 01 — Self-Hosted Production Profile + Hardening (PLAN)

**Goal:** stand up a preferred self-hosted `production` profile that can pass
B1–B8 + B10 with real evidence on a no-GPU ~16 GB host, hardened per the
security architecture, with cloud/GPU as the values-only extension for B9.
**Spec:** `docs/SELF-HOSTED-PRODUCTION-ARCHITECTURE.md`.

**Success criteria:** all of B1–B8 + B10 flip Partial→Done on real self-hosted
evidence; B9 either receives real cloud/GPU trainer evidence through the same
provider-manifest/custody path or remains Partial; the security must-dos are
implemented; 6 §16 SLOs re-proven on the real path; a real LongMemEval R@5 is
recorded; `forbid_local:true` and all gates remain enforced; full suite + CI
green. This plan does not authorize marking B9 DEFERRED-BY-DESIGN for current
strict 100%.
