# Phase 08 / Plan 01 — Self-Hosted Production Profile + Hardening (PLAN)

**Goal:** stand up a preferred self-hosted `production` profile that can pass
B1–B8 + B10 with real evidence on a no-GPU ~16 GB host, hardened per the
security architecture, with cloud/GPU as the values-only extension for B9.
**Spec:** `docs/SELF-HOSTED-PRODUCTION-ARCHITECTURE.md`.

**Success criteria:** all of B1–B8 + B10 flip Partial→Done on real self-hosted
evidence; B9 either receives real cloud/GPU trainer evidence through the same
provider-manifest/custody path or remains Partial; the security must-dos are
implemented; 6 §16 SLOs re-proven on the real path; a real LongMemEval R@5 is
recorded; `forbid_local:true` and all gates remain enforced; full suite + CI
green. This plan does not authorize marking B9 DEFERRED-BY-DESIGN for current
strict 100%.

### 8.3 — Identity / secrets / TLS hardening
- [ ] Sealed Vault (raft + transit auto-unseal; remove dev root token); AppRole/workload identity; audit device on; TLS from step-ca.

- [ ] step-ca ACME provisioner; Caddy enrolls; root in system trust; mTLS between services (verify SAN).

### 8.4 — Object store / observability
- [ ] SeaweedFS (native AES256) or MinIO; **mandatory** `MNEMOSYNE_OBJECT_STORE_ENCRYPTION=aesgcm` via Vault-transit key provider; boot-time refuse-to-start if `none`.
- [ ] Grafana hosted dashboard (`mode=hosted_url`) + vmalert tripwires + freshness + auth.

### 8.5 — Security must-dos (no gate weakened)
- [ ] Fail-closed production defaults: MCP `require_session=True`; tenant/role/trust from verified session only; fail-closed provenance.
- [ ] Postgres role separation DDL (`mnemosyne_app` NOSUPERUSER/NOBYPASSRLS; `mnemosyne_consolidator` sole write) + ops-check live-probing `rolsuper`/`rolbypassrls`.
- [ ] **Gate integrity:** only where a real capture attempt exposes an
  attestation-only gap, extend high-value `*-ops-check` to re-execute against
  live infra (forge tokens; real forget→re-read 404 + Vault key gone; provider
  round-trip) and sign evidence bundles with a collector-only key the gate
  verifies.
- [ ] Container/supply-chain: digest-pin all images; policy-as-code CI gate (no `docker.sock`, non-root, read_only, cap_drop ALL, no-new-privileges, limits); Trivy/Grype/Syft + gitleaks; cosign verify-at-deploy.
- [ ] Network: Caddy sole ingress; internal-only tiers; single SSRF egress chokepoint + default-deny allowlist; lint against raw HTTP clients.
- [ ] Privilege-separate Mnemosyne (edge API/MCP vs back consolidator/KMS).
- [ ] Tamper-evident hash-chained append-only audit log (Vault-HMAC) + pgaudit + out-of-band WORM copy.
- [ ] Data: LUKS for PGDATA/Vault storage; encrypted PITR backups + scheduled verified restore; per-tenant-scoped crypto-shred keys.
