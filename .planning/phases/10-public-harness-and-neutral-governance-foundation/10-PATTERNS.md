# Phase 10 Patterns

## Harness

- Public CLI subprocesses are the only system seam.
- Registry metadata is data, never executable configuration.
- Full commit + SHA-256 + declared license + split role are mandatory.
- New output directory, temp writes, atomic rename, relative containment, no
  symlinks, complete inventory, canonical hashes.
- Fixed allowlisted child environment and secret-shaped value rejection.
- `deterministic_retrieval` and `llm_judged_qa` are disjoint schema enums.
- Smoke/development results are permanently non-headline.

## Governance

- Versioned policy documents with explicit `prepared`, `operator-adopted`, or
  `active` status; source code cannot promote external states.
- Permanent Mnemosyne COI and equal-treatment firewall.
- Public dockets/minutes/register templates; no silent score retraction.
- Versioned changes preserve frozen historical boards.
- L0 source readiness may pass while GOV-001 external activation remains partial.
