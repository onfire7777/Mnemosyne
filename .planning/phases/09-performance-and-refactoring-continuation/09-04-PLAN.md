# 09-04 Plan: Provider Contract Conformance CI

## Goal

Make `/embed` and `/rerank` contract drift fail in CI across the Python
embedding service, Python HTTP adapters, and Rust `mneme-providers` sidecar
without flipping provider defaults or claiming bake-off evidence.

## Scope

- Add a shared provider contract fixture under `tests/fixtures/`.
- Drive the fixture through `services/embedding/app.py`.
- Drive the fixture through `HttpEmbeddingProvider` and `HttpReranker`.
- Drive the fixture through Rust sidecar unit tests.
- Add wire-compatible list-input `/embed` support to the Rust sidecar.
- Add a dedicated `provider-conformance` GitHub Actions job.
- Update provider docs, bake-off docs, blueprint status, and Phase 09 planning.

## Out Of Scope

- TEI deployment or default selection.
- Model-backed `--features models` CI.
- Throughput-true sidecar batching benchmarks.
- Provider bake-off promotion.
- Tier-B/operator evidence claims.

## Acceptance

- Python provider contract tests pass.
- Embedding service self-test passes in forced fallback mode.
- Rust sidecar tests and clippy pass.
- CI contains a dedicated provider conformance lane.
- Docs preserve the remaining bake-off/default-selection gap.
