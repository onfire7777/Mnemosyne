# Phase 09.1: Preserve Caller Context Across Search, Deep Search, and Explain - Pattern Map

**Mapped:** 2026-07-10  
**Scope:** Planner-ready file inventory, data flow, closest analogs, and regression seams  
**CBM project:** `Users-admin-Mnemosyne` (`ready`, 15,757 nodes / 61,759 edges)

## Executive Pattern

This phase should follow the repository's existing public-read pattern, not introduce a new layer:

```text
CLI / JSON-RPC / official SDK
        |
        v
MemoryTools.search | deep_search | explain
        |
        +-- MemoryTools._read_context(...) -> canonical filt mapping
        |
        v
engine.retrieve(...) or engine.deep_search(...)
        |
        v
shared retrieval pipeline -> may_read_item(...)
```

The closest complete analog is the `export`/`get`/`graph_timeline` family. Their Python facades expose the same optional caller-context fields with `role="reader"`; `export()` constructs the canonical context via `_read_context()`; and their CLI handlers expand `_read_context_kwargs(args)` after parsers receive `_add_read_context_args(...)`.

The change should remain limited to two production files. Generated MCP schemas, JSON-RPC dispatch, and the official SDK are downstream consumers of `MemoryTools` signatures and should be verified but not modified.

## Production Signatures and Concrete Edits

### `src/mnemosyne/mcp_tools.py`

Current asymmetry:

```python
def search(
    self,
    tenant_id: str,
    query: str,
    branch: str = "main",
    min_trust_tier: int | None = None,
    max_trust_tier: int | None = None,
    max_sensitivity: int | None = None,
    role: WriteRole = "agent",
    user_id: str | None = None,
    capability_tags: list[str] | None = None,
    purpose: str | list[str] | None = None,
    residency: str | None = None,
    region: str | None = None,
    break_glass: bool = False,
    lawful_basis: str | list[str] | None = None,
) -> dict[str, Any]: ...

def deep_search(
    self,
    tenant_id: str,
    query: str,
    branch: str = "main",
    role: WriteRole = "agent",
) -> dict[str, Any]: ...

def explain(
    self,
    tenant_id: str,
    query: str,
    branch: str = "main",
) -> dict[str, Any]: ...
```

Target shared caller-context suffix, matching `_read_context()` and `export()`:

```python
role: WriteRole = "reader",
user_id: str | None = None,
max_sensitivity: int | None = None,
capability_tags: list[str] | None = None,
purpose: str | list[str] | None = None,
residency: str | None = None,
region: str | None = None,
break_glass: bool = False,
lawful_basis: str | list[str] | None = None,
```

Canonical helper contract:

```python
context: dict[str, Any] = {
    "tenant_id": tenant_id,
    "tenant": tenant_id,
    "role": role,
}
# user_id/residency/region only when truthy
# max_sensitivity when not None, so zero is preserved
# capability_tags copied only when non-empty
# purpose/lawful_basis when not None
# break_glass only when true
```

Implementation shape:

```python
filt = self._read_context(
    tenant_id,
    role=role,
    user_id=user_id,
    max_sensitivity=max_sensitivity,
    capability_tags=capability_tags,
    purpose=purpose,
    residency=residency,
    region=region,
    break_glass=break_glass,
    lawful_basis=lawful_basis,
)
```

For `search()` only, append trust controls after constructing the context:

```python
if max_trust_tier is not None:
    filt["max_trust_tier"] = max_trust_tier
elif min_trust_tier is not None:
    filt["min_trust_tier"] = min_trust_tier
```

Then preserve the current calls and response behavior exactly:

```python
self.engine.retrieve(..., filt=filt)       # search
self.engine.deep_search(..., filt=filt)    # deep_search and explain
self._record_retrieval(result.to_dict(), start)
return result.to_dict()
```

Why no engine edits: Local, SQLite, and Postgres already share the exact delegator shape:

```python
def deep_search(..., filt: dict[str, Any] | None = None) -> RetrievalResult:
    return self.retrieve(..., deep=True, filt=filt)
```

### `src/mnemosyne/cli.py`

Canonical dispatcher helper:

```python
def _read_context_kwargs(args: argparse.Namespace) -> dict[str, Any]:
    return {
        "role": getattr(args, "role", "reader"),
        "user_id": getattr(args, "user", None),
        "max_sensitivity": getattr(args, "max_sensitivity", None),
        "capability_tags": getattr(args, "capability_tag", None) or None,
        "purpose": getattr(args, "purpose", None),
        "residency": getattr(args, "residency", None),
        "region": getattr(args, "region", None),
        "break_glass": bool(getattr(args, "break_glass", False)),
        "lawful_basis": getattr(args, "lawful_basis", None),
    }
```

Canonical parser helper:

```python
def _add_read_context_args(parser: argparse.ArgumentParser) -> None:
    parser.add_argument("--role", default="reader", choices=[...])
    parser.add_argument("--user")
    parser.add_argument("--max-sensitivity", type=int)
    parser.add_argument("--capability-tag", action="append", default=[])
    parser.add_argument("--purpose")
    parser.add_argument("--lawful-basis")
    parser.add_argument("--residency")
    parser.add_argument("--region")
    parser.add_argument("--break-glass", action="store_true")
```

Target dispatcher pattern, already used by `cmd_get`:

```python
emit(tools.get(args.tenant, args.id, branch=args.branch, **_read_context_kwargs(args)))
```

Apply that shape to all three commands. `cmd_search` continues to pass `min_trust_tier` and `max_trust_tier` explicitly, then expands the context helper. In `build_parser()`, leave tenant/query/branch plus search-only trust flags explicit and call `_add_read_context_args(search|deep|explain)` once per parser.

## Generated Schema and Transport Flow

### No `TOOL_SPEC` edit

`TOOL_SPEC` deliberately lists only the concise documentation hints `tenant_id` and `query` for these tools. `_to_mcp_tool_spec()` obtains the real contract from `inspect.signature(MemoryTools.<method>)` and `get_type_hints()`. Defaulted parameters become optional schema properties with a `default`; only parameters without defaults enter `required`; `additionalProperties` remains false.

Therefore the signature change automatically flows to:

```text
MemoryTools signature
  -> _to_mcp_tool_spec()
  -> MnemosyneMcpServer.tool_specs / tools/list
  -> CLI `mneme tools`
  -> JSON-RPC validation + call_tool
  -> official SDK list_tools/call_tool
```

### Signed-session binding gets parity for free

`MnemosyneMcpServer._bind_session_identity()` inspects method parameter names. When `deep_search` and `explain` gain `user_id` and `role`, it will automatically:

- bind/validate `tenant_id`;
- bind/validate `user_id`;
- overwrite self-asserted `role` with the signed session role.

Purpose, capability, sensitivity, residency, region, lawful basis, and break-glass remain explicit request inputs. `prepare_tool_arguments()` and `build_sdk_server()` need no changes; they already share binding, schema validation, and `call_tool()` dispatch.

## Authorization Sink and Non-Leakage Boundary

`may_read_item()` is the existing sink and must remain unchanged. It already enforces:

- tenant and policy-tenant equality;
- reader/agent/consolidator/operator ceilings;
- S4 denial and two-sided operator break-glass;
- item maximum sensitivity;
- role, capability, principal, scope, purpose, residency/region, and lawful-basis gates;
- raw-field redaction/denial.

Its contract explicitly states that denies are existence-silent at the caller layer. Tests may inspect an internal `AccessDecision.reason` only in unit policy tests; Phase 09.1 must not add that reason to public retrieval results.

## No-Change Boundaries

Do not modify:

- `src/mnemosyne/access_policy.py` — enforcement already exists and is correct;
- `src/mnemosyne/engine.py`, `sqlite_engine.py`, or `postgres_engine.py` — all already forward `filt` through `deep_search(..., deep=True)`;
- `src/mnemosyne/mcp_server.py` — schemas, identity binding, JSON-RPC, and SDK are signature-driven;
- `TOOL_SPEC` argument hints — they are not the authoritative generated property list;
- retrieval response models — denied reads retain the normal empty/abstained response shape;
- runtime residency/provider policy — `runtime_residency` is outside this public caller-context phase.
