# Phase 09.1 — Security

> Plan-time authorization-context threats verified against the shipped implementation and cross-surface regression suite.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| CLI / JSON-RPC / official SDK → `MemoryTools` | Caller-controlled read context enters the public facade. | Tenant, principal, role, sensitivity, capability, purpose, residency/region, lawful basis, break-glass. |
| `MemoryTools` → retrieval engine | Canonical context becomes the engine `filt` contract. | Authorization identity and policy constraints. |
| Retrieval engine → public response | Authorized results and explanation metadata leave the trusted policy boundary. | Content, CID, provenance, support IDs, result metadata. |
