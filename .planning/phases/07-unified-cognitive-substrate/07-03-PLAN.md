<objective>
Make "always-on" real and safe. Run the cognitive cycle continuously with a TIERED heartbeat — woven into every operation (engaged tier) plus a sparse, thresholded idle default-mode tick (replay, dream, gist re-derivation, self-triggered consolidation). Because the loop never sleeps, promote the anti-rumination regulator and the interoceptive proto-self from advisory shadow components to HARD, always-on safety primitives. The dreamer becomes always-recruitable, its output born at low groundedness (P2). Add four structural safeties: the self-generation budget rail (H4), the answer-grounding floor (H5), broadcast-as-data (H9), and the fail-closed circuit-breaker (H6).

CRITICAL: this is where confabulation/rumination/compute risk is highest. The plan ships ONLY if rumination_rate stays ~0, heartbeat compute is bounded and reported, and no reliability guardrail regresses. The self-loop's outputs never sit on the answer critical path except as low-groundedness, clearly-flagged hypotheses. This plan retires the default-off shadow SERVICE (the loop is now native); it does NOT yet remove the `shadow_only`/`enabled` booleans (that is P5).
</objective>
