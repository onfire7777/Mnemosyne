# 09-12 Plan: Native Wheel Install Smoke

## Goal

Close the source-owned part of the native release gap where CI proved wheel
builds but did not prove the built artifacts install and expose the parity
contract.

## Scope

- Keep the existing macOS arm64 and Linux x86_64 `native-wheels` build matrix.
- Add Python 3.12 setup to the native wheel job.
- Install the wheel produced by the same job from `rust/mnemosyne-native/dist`.
- Import `mnemosyne_native` and assert the public parity marker.
- Keep pure-Python fallback and runtime defaults unchanged.

## Out Of Scope

- Expanding the full release matrix to Linux aarch64, macOS x86_64, or Windows.
- Publishing wheels to PyPI.
- Flipping native acceleration defaults beyond the existing optional import path.
- Claiming production/operator runtime-flip evidence.

## Acceptance

- The native wheel CI job fails if no wheel is produced, the wheel cannot be
  installed, or `mnemosyne_native.parity_marker()` changes.
- Existing artifact upload stays intact.
- YAML parses locally.
- A local built-wheel install/import smoke passes on the current host.
