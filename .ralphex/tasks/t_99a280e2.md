### Task 1: Build the bounded protocol and runtime skeleton
- [x] Create a standalone Rust crate at `services/answering-ort` with a JSON request/response protocol for `embed`, `rerank`, and `read`, bounded to a 64 KiB request body, 2,000 query characters, 20 evidence rows, 24,000 evidence characters, rank width 8, one in-flight request, and a 30-second deadline seam.
- [x] Make malformed, oversized, unsupported, timed-out, or unavailable-session requests return deterministic fail-closed errors; do not fabricate model outputs or silently fall back.
- [x] Implement one process-wide shared runtime/session abstraction. Support an optional local ONNX model path without downloading models. Expose explicit configuration seams for CPU arena disabled, memory-mapped model bytes, intra-op threads capped at two, and inter-op threads fixed at one.
- [x] Keep the crate independent from Python and do not add any Python dependency or integration change.

### Task 2: Expose local-only transports and test them
- [x] Serve TCP only on loopback addresses and support a Unix-domain socket on Unix with stale-socket cleanup and owner-only socket permissions; reject non-loopback TCP binds before listening.
- [x] Add unit/integration-style Rust tests inside the allowed source files for protocol bounds, malformed input, unsupported operations, fail-closed unavailable runtime behavior, shared-session identity/configuration, loopback rejection, and deterministic responses.
- [x] Add crate-local `/target` ignore only and document build, configuration, protocol, security boundaries, placeholder status, and validation without claiming measured parity or production readiness.
