# Change and Correction Control

Version: 0.1.0  
Status: draft; External activation required

Policy, dataset, adapter, harness, judge, and scoring changes use semantic
versions and a public change log. Proposals include rationale, affected runs,
compatibility, validation evidence, author conflicts, review record, and the
effective date. Material methodology changes require board approval after a
public comment period.

Published run records are immutable. We never silently retract or overwrite a
score. Errors produce a versioned correction that preserves the original,
states cause and impact, links the approving decision, and identifies whether
re-ranking is required. Withdrawn or ineligible records remain discoverable
with their status and reason.

Emergency security changes may be temporarily embargoed, but still require an
immutable decision record and later disclosure. No emergency path can waive
the operator firewall or convert draft governance into active governance.
