Mnemosyne A unified agent-memory architecture — the best of GBrain, MemPalace, the academic literature, and ~20 production systems, with no compromises.

Core thesis. Not one big vector database. An event-sourced, multi-store memory operating system: an immutable evidence layer (everything said/done/observed, verbatim, never destroyed) plus rebuildable derived projections (current facts, relationships, preferences, skills, lessons), under a high-precision retrieval engine and a three-timescale recursive learning loop. Completeness lives in storage; precision lives in retrieval. That single split reconciles “total recall” with “good retrieval.”

Nine typed memory stores

One immutable evidence spine and eight derived, rebuildable projections. Different information needs different write rules, retrieval, and lifecycle — so it is never one undifferentiated blob (CoALA, extended).

The retrieval engine — a planner, not a lookup

Hybrid multi-channel recall → fuse → activation-score → rerank → dedup → order against the U-curve. Two modes: fast (default, low-latency) and deep (exhaustive, guarantees the exact original is recoverable).

Activation score (why it’s memory, not search)

Borrowed from ACT-R + Generative Agents — rank by the estimated probability a memory is useful right now:

activation(m) =  w_b · base_level(m)          # frequency + power-law-decayed recency
              +  w_s · spreading(m, query)     # graph proximity to query entities (PPR)
              +  w_i · importance(m)           # salience (decays over time)
              +  w_r · relevance(m, query)     # fused dense + lexical (RRF)
              +  noise
base_level(m) = ln( Σ_k age(access_k)^(-0.5) )   # accessed-often-&-recently ⇒ retrievable
stop when marginal_gain < retrieval_cost          # principled dynamic top-k

Weights are config in Phase 1, then learned (and gated) by the cold loop in Phase 5.

Completeness → storage

Evidence ledger is append-only and lossless. Nothing important is deleted — only superseded, decayed in salience, or compacted with a pointer back to the verbatim original. Deep mode can always reconstruct the exact source.

Precision → retrieval

Assemble the smallest high-signal context. The literature is decisive: stuffing context degrades quality (“lost in the middle”, “context rot”, “power of noise”). So default retrieval is tight; exhaustive is opt-in.

Three recursive learning loops

Self-learning, self-adapting, self-improving, self-optimizing — at three timescales, each a closed observe → diagnose → propose → validate → commit → monitor cycle. The recursion is real: memory operates on memory, skills compose skills, and the management policy is itself improvable memory.

🔥 Hot loop

intra-task · seconds
  • retrieve → reason → act → verify with tools → correct
  • recall boosts strength (reconsolidation)
  • emits candidate lessons/prefs + a logged trajectory

🌙 Warm loop

idle · “sleep-time” · mins–hrs
  • replay prioritized episodes (importance·novelty·surprise)
  • episodic→semantic; induce workflows; distill lessons
  • resolve contradictions; decay & prune
  • runs on a separate consolidator that owns write authority

❄️ Cold loop

cross-task · days · meta
  • learns the policies themselves: routing, ranking weights,
  • write decisions (ADD/UPDATE/DELETE/NOOP), cadence
  • RL on measured outcomes (Memory-R1) — gated, versioned

🔒 The one rule & the immutable invariant

No candidate memory ever self-certifies. Every promotion passes an external gate — tool-grounded for facts, regression-tested for procedures/lessons/policies, corroborated for deletes.

Promotion gate
  1. Hold out a fixed regression suite of already-solved tasks (built from real corrections).
  2. Re-run with the candidate injected; promote only if non-inferior & no protected task regresses & margin > noise.
  3. Source data disjoint from the suite (no teaching-to-the-test).
  4. Commit versioned & diffable; rollback is transitive (reverting a lesson invalidates memories derived under it).

Outer invariant: the reward signal, the validator, the regression suite, and the safety/identity rules live outside the self-editable surface and are enforced structurally — because STOP & reward-tampering results show anything editable is eventually gamed.

Memory as a credential-grade control surface

Persistent memory makes prompt injection durable (OWASP ASI06). Defenses are architectural, not detection-based — “catches 95%” means the adversary uses the other 5%.

The hard rules

  • Retrieved content is data, never instruction (sanitize on ingest + retrieval).
  • Untrusted-derived memory never enters the system prompt (the MemoryTrap fix).
  • Per-tenant / per-user isolation — nullifies MINJA’s shared-memory assumption (the #1 defense).
  • Write-gating: sensitive/destructive ops need higher auth + corroboration, and are reversible.
  • User-facing agent can’t destructively edit memory — only the consolidator can.
