## Reproduction

Run from `/Users/admin/Mnemosyne` after `./infra/scripts/setup-all.sh`:

```bash
source infra/keycloak/out/oidc.env
source infra/vault/out/vault.env
source infra/c2pa/out/provenance.env
export MNEMOSYNE_IDP_TOKEN="$(./infra/scripts/keycloak-token.sh agent-a agent-a-password)"
export MNEMOSYNE_OBJECT_STORE_ENCRYPTION=aesgcm

.venv/bin/python -m mnemosyne.cli --store /tmp/mnemosyne-tierb-soak/store.json \
  deployment-soak \
  --soak-manifest /tmp/mnemosyne-tierb-soak/manifest.json \
  --evidence-dir /tmp/mnemosyne-tierb-soak/evidence \
  --check-timeout 60

.venv/bin/python -m mnemosyne.cli --store /tmp/mnemosyne-tierb-soak/store.json \
  release-audit \
  --evidence-manifest /tmp/mnemosyne-tierb-soak/evidence/manifest.json \
  --require-command idp-jwks-live-check \
  --require-command provider-check \
  --require-command provenance-trust-check \
  --require-provider-check object_key_manager \
  --require-provider-check retrieval_backends \
  --allow-provider-local
```

Do not commit anything under `infra/*/out/`; those directories contain generated
tokens, private keys, wrapped key sidecars, and local trust material.
